# 文本证据层（G1 / G5 / G6）

这一层的目标不是“读懂新闻”，而是**把一条消息钉成可回测、可审计的证据**。

## 三条不可让渡的规则

1. **Agent 负责发现，库负责证据。** 抓取由调度 agent 发起，但入库只认
   `原文 + 内容 hash + 抓取时间 + 来源`；模型摘要、记忆、二次转述都不算证据。
2. **首次公开时间 = 可见时间。** 抓取时间晚于公开时间，不能用抓取时间冒充；
   收盘后（15:00）公开的事件当日不可见，顺延到下一交易日。
3. **辟谣只改未来，不改历史。** 撤稿时间之后的查询看不到事件，之前的查询照旧能看到——
   否则“当时确实这么报道过”这个事实就被抹掉了。

## G1 采集快照

- `snapshot_id = hash(url + content_sha256 + source_id)`，不含时间，同内容自动去重；
- 原文按原始字节落盘（不转码、不压缩），索引 append-only；
- `verify()` 能发现 raw 文件被篡改。

## G5 来源分级

| tier | 含义 | 例 |
|---|---|---|
| 1 | 官方 | 交易所/证监会/公司公告 |
| 2 | 通讯社 | 新华社/路透/彭博 |
| 3 | 财经媒体 | 财新/东财/雪球 |
| 4 | 社媒 | 微博/X |
| 5 | 传闻/未知 | 无法识别来源 |

`arbitrate()`：tier 小者优先 → 同 tier 取更早公开 → 再同按 `evidence_id` 字典序（保证确定性）。
理由码随结果返回，便于审计“为什么选它”。

## G6 事件 PIT

- 事件字段：`actor / action / object / stage(proposed→reviewed→passed→effective) / first_published_at / effective_at / evidence_ids / retracted_at`；
- `visible_at(event, as_of)`：唯一判据是首次公开时间与撤稿时间；
- `audit()`：生效早于公开、撤稿早于公开、重复 id、stage 回退 —— 一律 BLOCKED；
- `pit_frame()`：把可见性展开成 `trade_date × event_id` 的布尔矩阵，供特征构造使用。

## 尚未包含（v0.5 计划）

- 事件抽取（规则 + LLM 双通道，产出候选 + 置信）；
- 实体消歧与关键人物图谱；
- 事件→标的映射（强度分级）。

这些模块的产出只能是“候选”，落库仍需人工审与规则固化。
